# Proxima Nova

The site uses **Proxima Nova**. Add these font files here (you must have a license):

- `ProximaNova-Regular.woff2` (weight 400)
- `ProximaNova-Semibold.woff2` (weight 600)
- `ProximaNova-Bold.woff2` (weight 700)

You can export .woff2 from [Adobe Fonts](https://fonts.adobe.com) (if you have Proxima Nova there), or from your font vendor. If the files are missing, the site falls back to system fonts.
